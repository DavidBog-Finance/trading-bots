Aero Setup Plan

Your picks, with duplicates merged into 21 things to set up. Four trading extras are saved for phase 2. Everything below except phase 2 is built into the new download.

Local AI and Claude now work together all the time. Before, the plan was "Claude until the Pro limit, then local." Now each one does the job it's best at, every hour:

  1. Local AI reads every headline first. It's free and never runs out, so it handles the volume: most news is noise.
  2. Claude gets the headlines that matter, in this order: news about something you own, critical events (hacks, bankruptcy, takeovers, dilution, guidance, lawsuits), then anything the local model rates important.
  3. Claude spot-checks 1 in 10 of the rest. Each night the server compares the two. If the local model is missing important news, more goes to Claude. If Claude keeps confirming noise, less does.
  4. Claude's usage is spread across the hour (30 calls by default). The agents and news about your holdings can use all of it. Lower-priority checks stop at a smaller share, so the important work always has room and your plan gets used steadily instead of running dry.

The local model never trades and can't start a buy on its own. If it rates news about something you own as serious, an agent wakes up and Claude decides. If Ollama goes down, Claude takes over all the scoring.

Phase 2: saved for later

These four need a few weeks of the scorecard and the data store first, so they're not in this build:

  • Shadow strategies on paper tests other rule sets on paper next to the real ones.
  • Earnings and macro calendar keeps the agents out of earnings and Fed days unless they mean to be in.
  • Trading dashboard puts positions, profit and loss, the scorecard and Claude usage on one page.
  • Tax ledger keeps a running list of trades and gains, ready to export at tax time.

Setup order

1. Hardware session (an hour)Clean the fans, re-paste, check the battery for swelling (remove it if swollen). Plug in Ethernet.
2. Install Ubuntu 24.04From a USB stick. Then copy the trading-bots folder over.
3. Run the server scriptsudo bash linux/server-setup.sh your-ntfy-topic sets up the driver, GPU cap, lid and sleep, updates, Docker, Tailscale and the firewall. Restart afterwards.
4. Run the installerbash linux/install.sh asks you to sign in to Claude once, runs the tests, starts the bots as a service, and starts all the web apps.
5. Point your router's DNS at the AeroThat turns on ad blocking for the house. Then choose the Aero in Time Machine on your Mac.
6. Paper trade for at least a monthWatch the Friday scorecard before you think about real money.

Full steps and the page address list are in linux/README.md in the download.
