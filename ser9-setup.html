SER9 Pro Setup Plan

The SER9 Pro takes over everything the Aero plan described: the trading bots, the Claude agents, local AI and the home apps. The Aero goes on the side. Your Mac and iPhone are how you watch it, prompt it and use it.

Nothing about how the trading works changes. It's the same code, the same safety rails and the same paper-first rule. Only the box it runs on changes.

  1. Bots and agents run 24/7 on the SER9 as a service that starts by itself after a reboot or power cut.
  2. Claude Code is installed on the SER9 and logged in to your Pro plan once. The agents use it in the background with no API key.
  3. Local AI and Claude work hand in hand, the same as before. The local model reads every headline and Claude gets what matters, paced through the hour. Local AI never trades.
  4. The Mac stops running bots. It becomes a normal laptop again, and it backs up to the SER9 with Time Machine.

Setup order

1. Plug in and set the BIOSEthernet to the router. Press Delete at power-on and set "Power on after AC loss" to On.
2. Install Ubuntu Server 24.04From a USB stick made on your Mac (balenaEtcher). This erases Windows. Name the computer ser9 and tick "Install OpenSSH server". Then copy the trading-bots folder over from the v4 download.
3. Run the server scriptsudo bash linux/server-setup.sh your-ntfy-topic sets up the kernel and graphics, sleep, updates, Docker, Tailscale and the firewall. Restart afterwards with sudo reboot.
4. Log in to Claude Codecurl -fsSL https://claude.ai/install.sh | bash, then claude and log in with your Pro account. Then cp .env.example .env and fill in your Alpaca paper keys and ntfy topics.
5. Run the installerbash linux/install.sh runs the tests, starts the bots as a service, and starts the web apps. The first run asks you to set passwords in linux/services.env, then you run it again.
6. Switch the Mac off bot dutyOn the Mac: bash mac/uninstall.sh. Then point Time Machine at the SER9, and your router's DNS at the SER9 for ad blocking.
7. Paper trade for at least a monthWatch the Friday scorecard before you think about real money.

Full steps and every page address are in linux/README.md in the v4 download. The Aero can still run the same scripts later if you want it back.
