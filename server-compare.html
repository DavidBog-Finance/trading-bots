Gigabyte Aero 14 vs M3 MacBook Pro

Which laptop should stay at home, plugged in, running the bots, the news watcher and the Claude agents around the clock?

Use the Aero 14 as the bot server. The job is tiny: a Python program that wakes every 30 seconds, makes a few web requests and calls Claude Code. Either laptop is far more than enough. What decides it is that the Aero already sits in one spot doing nothing, while your MacBook goes where you go. Moving the bots off the Mac means closing its lid or taking it out never stops the trading.

Two conditions: install Ubuntu Linux on the Aero instead of running Windows 10, and deal with its roughly nine-year-old battery before leaving it on the charger 24/7 (details below).

Before the Aero runs 24/7

  1. Check the battery. Look at the laptop on a flat table. If the case bulges, the trackpad has lifted, or it rocks, the battery is swelling. Stop charging it and replace or remove it. A healthy one is still at 100% charge all day; if Gigabyte Control Center offers a charge limit on your model, set it to 60–80%. Otherwise, the safest setup is to unplug the internal battery and run on the 150 W adapter alone. The trade-off is that a power cut shuts it down. It reboots on its own if the BIOS has a "power on after AC loss" option, and the bots pick up where they left off.
  2. Clean it. Blow the dust out of the fans. New thermal paste is optional, since the bots barely load the CPU.
  3. Install Ubuntu 24.04 LTS from a USB stick (you'll need about 8 GB). This wipes Windows, so copy off anything you want first. Linux is the standard home for always-on servers: it doesn't nag about updates, doesn't restart on its own, and needs no screen or login to keep running.
  4. Make it headless. Set the lid switch to "ignore" and turn off suspend. Install Tailscale (free), which lets your MacBook and iPhone reach it from anywhere over SSH. Use Ethernet through a USB adapter if your router is nearby, since it's steadier than Wi-Fi.
  5. Install the bots. Install Claude Code, run claude and log in with your Pro account, copy over the repo and .env, then run the Linux installer. I can add a linux/install.sh that sets up a systemd service with auto-restart, just like the Mac version.

If you'd rather keep the MacBook

It works as built: plugged in, lid open, never taken out. The catch is that every time you take it with you, the agents, the news watcher and the stop-losses pause until it's back home. Alpaca keeps your positions safe either way, and the rules bots catch up the next day. Choose this only if the Aero's battery is swollen and you don't want to deal with it.
